# _ai_temp

Temporary workspace for the AI assistant.

Purpose:
- Keep ephemeral notes and working context while analyzing the repo.
- Safe to delete at any time. Nothing here is required for runtime/build.

Conventions:
- Do not store secrets or API keys here. If any appear, remove and rotate.
- Use `scratch.md` for throwaway notes.
- `.gitignore` keeps only this README and `scratch.md` tracked by default.
