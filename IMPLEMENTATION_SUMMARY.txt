  ARCHITECTURE
================================================================================

Three Queues (SQS + LocalStack):

  ① Prompt Queue ────────────→ Archie Consumer
                              (queue_consumer.py)
                                      │
                   ┌──────────────────┴──────────────────┐
                   │                                      │
             Status Query                          Admin Task
                   │                                      │
                   ▼                                      ▼
           get_task_status                    enqueue_for_lauren
                   │                                      │
                   ▼                                      ▼
           send_matrix_message            ② Lauren Work Queue
                                                          │
                                                          ▼
                                                  Lauren Consumer
                                                (lauren_consumer.py)
                                                          │
                                                          ▼
                                             classify_and_create_task
                                                          │
                                                          ▼
                                                  DynamoDB (OPEN/UNCLAIMED task)
                                                          │
                                                          ▼
                                                notify_archie_signal
                                                          │
                                                          ▼
                                            ③ Archie Signal Queue
                                                          │
                                                          ▼
                                              Archie Signal Consumer
                                            (archie_signal_consumer.py)
                                                          │
                                                          ▼
                                                send_matrix_message
                                                          │
                                                          ▼
                                                  Matrix/Element
                                                   (User notified)

================================================================================
  AGENT TOOLS (FINAL)
================================================================================

ARCHIE (3 tools):
  1. get_task_status — Query tasks with filters
  2. send_matrix_message — Reply in Matrix/Element
  3. enqueue_for_lauren — Queue admin task (async, non-blocking)

LAUREN (3 tools):
  1. classify_and_create_task — Full classification + creation
  2. create_task — Direct creation helper
  3. notify_archie_signal — Send signal to Archie

LAUREN DOES NOT HAVE (by design):
  ✗ claim_task — Humans do this via UI
  ✗ complete_task — Humans do this via UI
  ✗ update_task — Out of scope
  ✗ cancel_task — Out of scope

================================================================================
  SDK PATTERNS USED
================================================================================

✓ Agent Definition: Agent(name, instructions, tools, model)
✓ Function Tools: @function_tool decorator with async support
✓ Runner.run: SDK agent execution with context injection
✓ Lifecycle Hooks: AgentHooks & RunHooks for observability
✓ Guardrails: @input_guardrail & @output_guardrail with tripwires
✓ Context: RunContextWrapper[AgentContext] for dependency injection
✓ Tracing: Automatic OpenAI platform traces
✓ Multi-Agent: Code-based orchestration via queues

All patterns from: /external/openai-agents-python/

================================================================================
  QUICK START
================================================================================

1. export OPENAI_API_KEY=sk-...

2. cd agents && python scripts/init_matrix_infra.py && cd ..

3. docker-compose -f docker-compose.yml -f docker-compose.agents.yml up

4. curl -X POST http://localhost:8008/_matrix/client/r0/register \
     -d '{"username":"archie","password":"archie","auth":{"type":"m.login.dummy"}}'

5. cd agents && MATRIX_ACCESS_TOKEN=<token> python scripts/matrix_listener.py

6. Open Element → Connect to localhost:8008 → Invite @archie:localhost

7. Chat: "Book photos for 123 Main St"

8. See task appear in frontend UI (http://localhost:5173)
